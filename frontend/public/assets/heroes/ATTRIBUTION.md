# Hero sprite attribution

All files in this directory (`warrior.svg`, `mage.svg`, `archer.svg`, `guardian.svg`) are
project-authored placeholder illustrations created specifically for NagiGame. They are not
downloaded from any third-party asset pack, stock site, or game asset marketplace, and carry
no external license obligations.

They are simple flat cartoon-style vector placeholders meant to be replaced later with a
properly licensed sprite pack if desired.
